# Goblin v0.1.2 integration kit
Download the original index.html from GitHub main (blob 3bfdd937b04bb1aca6d6078c35600c560e7c4ef1). Keep a backup. Extract this kit, install Python 3 and Node.js if necessary, then run `python build.py /path/to/index.html`. The builder verifies the original blob, applies controls and graphics edits in a temporary directory, checks both scripts and writes a candidate ZIP beside the original. It never modifies the original or GitHub. The game still uses the existing Three.js CDN; no new assets required. Test candidate locally via a web server and on Quest 2 over HTTPS before manually replacing root index.html. Verify both hands, touch movement, dodge, enemy pursuit, repeated kills and save reload. Do not clear site data. This kit itself is not a deployable game.
